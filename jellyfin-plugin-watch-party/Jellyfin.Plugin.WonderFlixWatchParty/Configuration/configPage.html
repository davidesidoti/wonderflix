New titles

New movies, and new episodes of the series each user follows, are summed up in their notifications after 15 quiet minutes (2 hours at most). Turn it off before a big import: titles waiting are dropped. Turn it off before moving a library to another path too: every title would look new.

Seerr

As seen from the Jellyfin server. Empty: requests are off in WonderFlix.
Seerr → Settings → General → API Key.

Seerr webhook

In Seerr → Settings → Notifications → Webhook: turn it on, paste the URL and the JSON payload below, and tick only "Request Pending Approval" and "Request Available".
A new secret needs the new JSON payload in Seerr too.

Sonarr and Radarr

WonderFlix shows the upcoming episodes (Sonarr) and movies (Radarr) on its Home. The API keys stay on the server.
As seen from the Jellyfin server, with the URL base. Empty: no upcoming episodes.
Sonarr → Settings → General → API Key.
Empty: no upcoming movies.
Radarr → Settings → General → API Key.
Movies count by their digital release date.
Save first: the test uses the saved settings.

Password recovery

WonderFlix users link their Discord or e-mail, and get a code there when they forget the password. Administrators can't use it.
Discord Developer Portal → your app → Bot: the token, and turn on "Server Members Intent".
Invite the bot to your server (scope "bot", no permissions), then right click on the server → Copy Server ID (Discord developer mode).
STARTTLS, usually 587 (port 465 is not supported).
Users without a linked contact get a reminder in their notifications. 0: no reminders.
